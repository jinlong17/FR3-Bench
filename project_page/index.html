Abstract

Real-world financial receipts arrive blurred, faded, compressed, or partially occluded — and yet downstream workflows depend on extracting precise numbers from them for auditing, accounting, and fraud detection. Existing document restoration benchmarks optimise pixel-level fidelity (PSNR, SSIM, LPIPS) but never verify whether the restored output actually supports correct numerical reasoning. Existing receipt-QA benchmarks assume clean inputs and ignore restoration entirely.

We close this gap with FR³ (Financial Receipt Restoration and Reasoning): 1,200 paired degraded ↔ clean receipt images and 1,009 computationally-rich financial QA pairs spanning 16 calculation types (sums, averages, ratios, percentiles, standard deviations, …). Receipts are hand-designed for privacy, printed on a thermal printer, photographed with an OPPO smartphone, and then synthetically degraded. A method is scored primarily by reasoning accuracy — pixel fidelity alone is not enough.

The Two Coupled Tasks

Restoration is judged by what it enables, not just how clean it looks.

Task 1

Image Restoration

Recover a clean receipt image from its degraded counterpart. Text legibility and digit fidelity matter more than raw PSNR.

PSNR ↑ · SSIM ↑ · LPIPS ↓
Task 2

Financial Reasoning

Multi-step numerical reasoning across one or many receipts: time-windowed sums, per-category averages, statistical aggregates, percentile filters.

QA Accuracy (1% tolerance)

Sixteen Calculation Types

sum · average · percentage · range · maximum · minimum · median · difference · ratio · standard_deviation · variance · harmonic_mean · coefficient_of_variation · aggregation · percentile · interquartile_range

Get the Benchmark

Annotation JSONs ship with the repo. ~4.4 GB of images on HuggingFace.

git clone https://github.com/jinlong17/FR3-Bench.git
cd FR3-Bench
pip install -r requirements.txt

# Pull the images (~4.4 GB)
python data/download_data.py --out data/images

# Score a submission
python evaluation/run_eval.py \
    --gt data/annotations/val_qa.json \
    --pred submission.json
QA annotations · ~6 MB (shipped in repo)
Validation images · 789 MB (200 paired · HuggingFace)
Test images · 3.6 GB (1,000 paired · HuggingFace)
